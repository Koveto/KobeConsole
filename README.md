# KobeConsole

A Raspberry Pi 5 gaming console project.

## Goals

- Boot directly into a launcher
- Launch Python/Pygame games
- Support keyboard input
- Support Nintendo Switch Pro Controllers
- Experiment with online multiplayer
- Deploy to multiple Raspberry Pi 5 devices

## Hardware

- Raspberry Pi 5 Starter Kit MAX (x2)
- HDMI display
- Nintendo Switch Pro Controller(s)
